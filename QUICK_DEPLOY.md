## Step-by-Step for Railway (Quickest)

### 1. Push to GitHub
```bash
git add .
git commit -m "Ready to deploy"
git push origin main
```

### 2. Create Railway Account
- https://railway.app
- Sign up with GitHub
- Authorize access

### 3. Import Project
- "New Project" → "GitHub Repo"
- Select your kklogistics repo

### 4. Add Database
- "Add Service" → "Add from Marketplace"
- Select "MySQL"
- Wait for auto-setup

### 5. Configure Variables
```
DATABASE_URL=auto-set
NODE_ENV=production
PORT=8080
```

### 6. Deploy
- Click "Deploy"
- Wait 2-3 minutes
- Visit your URL

**Done! ✅ Your app is live**

## Environment Variables Needed

### Local Development
```
DATABASE_URL=mysql://root:password@localhost:3306/kklogistics_dev
NODE_ENV=development
```

### Production (Railway)
```
DATABASE_URL=<auto-generated>
NODE_ENV=production
PORT=8080
```

### Production (AWS/Others)
```
DATABASE_URL=mysql://user:pass@endpoint:3306/dbname
NODE_ENV=production
PORT=3000
AWS_REGION=us-east-1
S3_BUCKET_NAME=your-bucket
```

## After Deployment

### Verify It Works
1. Visit your app URL
2. Check frontend loads
3. Test API calls (open DevTools → Network tab)
4. Create a test driver entry
5. Check database saved it

### Enable Automatic Backups
- Railway: Automatic ✅

### Monitor Performance
- Railway: Click "Metrics" tab

- AWS: CloudWatch dashboard

- Add Sentry: https://sentry.io (free tier available)

## Database Backup

### Automatic (Railway)
- Daily backups included
- 30-day retention

### Manual Backup
```bash
# Export database
mysqldump -u user -p database > backup.sql

# Restore
mysql -u user -p database < backup.sql
```

### AWS RDS Automated
- Set backup retention: 7-30 days
- Automatic snapshots

## Common Issues & Quick Fixes

### "Build Failed"
```bash
# Rebuild with:
npm install --legacy-peer-deps
npm run build
```

### "Connection Refused"
- Check DATABASE_URL is set
- Check MySQL is running
- Restart service

### "Port 3000 in Use"
- Change PORT in environment
- Or: kill process using port 3000

### "Out of Memory"
- Railway/DigitalOcean: upgrade plan
- Local: increase Docker memory

## Production Domains

### Add Custom Domain to Railway
1. Project Settings → Domains
2. Add your domain (www.kklogistics.com)
3. Update DNS to point to Railway
4. Wait 5-10 minutes for SSL

### Add Custom Domain to DigitalOcean
1. App Platform → Settings
2. Add custom domain
3. Update DNS
4. SSL auto-configured

### Add Custom Domain to AWS
1. Route53 → Create hosted zone
2. Point domain DNS to Route53
3. Create A record → ALB/ELB
4. Set SSL via ACM

## Rollback to Previous Version

### Railway
1. Go to Deployments tab
2. Click previous deployment
3. Click "Redeploy"

### DigitalOcean
1. Go to Deployments
2. Select previous version
3. Click "Deploy"

```bash
git revert <commit-hash>
git push origin main
# Auto-redeploys
```
